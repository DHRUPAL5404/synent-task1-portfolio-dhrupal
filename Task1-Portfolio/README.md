# 🚀 Personal Portfolio Website

Welcome to my **Personal Portfolio Website**! This project was designed and developed as part of **Task 1** during the **Synent Technologies Internship Program**. It serves as a modern, interactive, and professional digital showcase of my technical skills, academic focus, and passion for web development and cybersecurity.

---

## 📌 Project Overview

This personal portfolio is a responsive, highly performant single-page website. Built primarily using semantic **HTML5** and custom modern **CSS3**, it is styled with a sleek hybrid dark/light theme, rich interactive animations, and responsive components. To ensure optimal performance and lightweight delivery, it features a completely **zero-JavaScript** navigation toggle and interactive elements, highlighting clean and robust frontend development practices.

---

## 🌟 Key Features

The portfolio is structured into distinct, high-impact sections designed to provide recruiters and visitors with a seamless browsing experience:

*   **📱 Responsive Navigation Bar**: A sticky header with a smooth, pure CSS responsive Hamburger menu utilizing the checkbox hack—offering zero-JS toggle capability on mobile devices.
*   **⚡ Dark-Themed Hero Section**: Features an interactive pulsing "Available for Internships" status badge and a futuristic profile card displaying a cybersecurity shield avatar.
*   **👤 Comprehensive 'About Me'**: A clean, light-themed section outlining professional values, academic focus, and a structured "Quick Info" details card.
*   **📊 Dynamic Skills Showcase**: Cards detailing confidence percentages and clean progress bars for my core toolkit, including:
    *   **HTML5 & CSS3** (Advanced layouts, design tokens, and media queries)
    *   **JavaScript** (DOM manipulation and dynamic rendering)
    *   **Java** (Object-Oriented Programming and robust back-end logic)
    *   **DBMS** (Relational databases, normalizations, and SQL query modeling)
*   **✉️ Sleek Contact Form & Sidebar**: Features contact information cards alongside an elegant, styled, pure CSS responsive contact form.
*   **✨ Rich Animations & Hover Effects**: Smooth hover transitions, floating card states, and scale animations that bring the user interface to life.

---

## 🛠️ Technologies Used

The core architecture of the website is built purely with native web technologies:

| Technology | Purpose | Key Implementation Details |
| :--- | :--- | :--- |
| **🌐 HTML5** | Structural Foundation | Semantic elements (`<header>`, `<main>`, `<section>`, `<footer>`), SEO meta tags, SVG icons, and accessibility standards. |
| **🎨 CSS3** | Visual Design & Styling | Custom styling with CSS Flexbox & Grid, HSL custom color tokens, smooth animations (`transition`, `@keyframes`), responsive media queries, and pure CSS state toggles. |

## 🚀 Getting Started Locally

To run this project on your local machine, follow these simple steps:

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/DHRUPAL5404/synent-task1-portfolio-dhrupal.git
    ```
2.  **Navigate to the Project Folder**:
    ```bash
    cd synent-task1-portfolio-dhrupal/Task1-Portfolio
    ```
3.  **Open index.html**:
    *   Simply double-click the `index.html` file in your file explorer to launch it in any modern web browser.
    *   *Alternative:* Open the folder in **VS Code** and use the **Live Server** extension for real-time live reloading.
